# Working on Spray Can

Spray Can is a macOS 14+ menu-bar app for keyboard-driven pointer control: it labels accessibility elements (plus optional on-device OCR text), grid cells, or scroll areas, and moves, clicks, drags, or scrolls when a label is typed. Read `README.md` for the user view and `docs/ARCHITECTURE.md` for the design.

## Layout

| Path | What lives there |
| --- | --- |
| `Sources/SprayCanCore/` | Pure, testable logic with no AppKit: targets and the generation-scoped `NavigationSession` (`Navigation.swift`), OCR merging (`Geometry.merge` / `mergeText`), label placement, connector uncrossing, color groups and HUD placement (`HintLayout.swift`), key mapping (`Keys.swift`), OCR language passes, refresh policy, appearance colors. |
| `Sources/SprayCanApp/` | AppKit/SwiftUI app: `AppController` (session coordination, clicks, drags, refresh), `Discovery` (accessibility scan, OCR, AX observers), `Overlay` (click-through panels, label drawing, HUD), `KeyboardCapture` (event tap), `MouseDriver`, `Settings` / `SettingsView`. |
| `Tests/SprayCanCoreTests/` | XCTest suite for the core package. |
| `Resources/` | `Info.plist`, assets, and `<language>.lproj/Localizable.strings`. |
| `scripts/` | Build, test, release, cask generation, localization check, live integration fixture. |
| `docs/` | Architecture, shortcuts, validation status, releasing. |

Put new logic in the core with tests whenever it can be expressed without AppKit; keep the app layer thin. `SprayCan.xcodeproj` is generated by `scripts/generate-project.py` and lists every `Sources/SprayCanApp/*.swift` file: rerun it after adding or removing an app source file.

## Conventions

- **Coordinates:** core types and targets use global Quartz points (top-left origin). Overlays draw in each display's Cocoa coordinates (bottom-left origin); convert with `Geometry.cocoa` only at the drawing edge. `HintLayout` works in whatever display-local space the caller passes (`HintPlacementStyle.yAxisUp` says which).
- **Sessions:** every activation increments `NavigationSession.generation`; all async completions (discovery, OCR, validation, clicks) must check the generation before touching state. Labels never change after the user types the first character.
- **Determinism:** label placement and color groups must be deterministic for the same input (tests compare against reversed input). Break ties by ID, never by iteration order of a dictionary or set.
- **Readability:** label placement changes must be checked by eye, not only by tests. Run `scripts/snapshot-labels.sh` on System Settings, Finder (list view), and a busy web page before and after, open the PNGs, and compare label counts and connectors. Labels should touch their element, sit beside its text, and never cover text or icons.
- **README images:** regenerate them with `scripts/render-docs.sh` only. It renders a synthetic example window (`DemoWindow` in `DocumentationRenderer.swift`) and passes every setting as a temporary command-line default, so images show factory settings. Never put real-window snapshots in the repository: they contain account names, device names, app lists, and other personal details. Read every regenerated image before committing.
- **Performance:** `HintLayout.place` runs on the main thread for every new target set (hundreds of targets in browsers). Keep per-label work local (filter by nearby boxes) and bounded.
- **Settings:** add a `@Published` property in `Settings` that persists via `UserDefaults` with an explicit default, and expose it in `SettingsView`.
- **Localization:** every user-visible string is an English key. Add it to **all** `Resources/*.lproj/Localizable.strings` (keep entries sorted) and run `python3 scripts/check-localizations.py`. CI also runs it with `--stringsdata build` after a build to catch strings missing from English.
- **Style:** match the surrounding code: compact Swift, short doc comments explaining *why*, no new dependencies, no network or analytics.

## Build and test

```sh
scripts/test.sh                 # core XCTest suite + localization check
scripts/snapshot-labels.sh com.apple.finder /tmp/finder.png   # real labels over a capture; add --prefix ab, --dump
scripts/build.sh                # universal (arm64 + x86_64) Release app in build/, ad-hoc signed
python3 scripts/verify-bundle.py 'build/Build/Products/Release/Spray Can.app'
scripts/integration-test.sh     # live event-tap/click fixture; needs an interactive desktop and Accessibility
swift scripts/ocr-smoke.swift   # Vision OCR smoke test
```

Use Xcode's toolchain (`DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`; the scripts set it when only Command Line Tools are selected). `build.sh` copies sources to `/tmp` before building because file-provider (iCloud) folders interfere with Xcode; if a later `codesign --verify` complains about "resource fork, Finder information, or similar detritus", run `xattr -cr` on the app first. The integration test injects real keyboard and mouse events, so only run it when nobody is using the machine.

## Documentation to keep current

- `CHANGELOG.md`: a section per release with a short validation note.
- `docs/SHORTCUTS.md` for any key change, `docs/ARCHITECTURE.md` for design changes, `docs/VALIDATION.md` for what was and was not verified.
- `README.md` (and translations) only for user-facing feature changes.

## Releasing and Homebrew

1. Update `CHANGELOG.md`, commit, and push `main` (CI runs tests and a universal build).
2. Tag and push: `git tag vX.Y.Z && git push origin vX.Y.Z`. `.github/workflows/release.yml` runs `scripts/release.sh`, which builds, signs (ad-hoc by default), zips `SprayCan-X.Y.Z-universal.zip`, writes the `.sha256`, generates `dist/spray-can.rb`, and publishes the GitHub release with those assets.
3. Update the tap [Kymer0615/homebrew-tap](https://github.com/Kymer0615/homebrew-tap): download the generated cask with `gh release download vX.Y.Z -R Kymer0615/spray_can -p spray-can.rb`, copy it to `Casks/spray-can.rb`, check that its `sha256` matches the release `.sha256`, commit as `spray-can X.Y.Z`, and push.
4. Users upgrade with `brew update && brew upgrade --cask kymer0615/tap/spray-can`.

See `docs/RELEASING.md` for Developer ID signing and notarization.
