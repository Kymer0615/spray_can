## 使いかた

1. **⇧⌘J** を押します。すべてのボタン、リンク、行、フィールドの、テキストのすぐ隣に短いラベルが表示されます。
2. ラベルを入力します。ポインタがその場所へ移動します。
3. **Return** を押すとクリックします。**2 回**押すとダブルクリック、**長押し**すると右クリックです。

マウスもトラックパッドも不要。カーソルを探す必要もありません。

ほかにも:

- **アクセシビリティが見逃すものまで見える。** オプションの Apple Vision OCR が、コントロールを公開していないアプリでも表示中のテキストにラベルを付けます。複数の言語を同時に認識できます。
- **滑らかなスクロールモード。** **⌃J** を押してから **HJKL** または矢印キーで操作します。ほかのキーを押すとモードを終了し、そのキーは App に届きます。滑らかさは調整可能で、VS Code などの Electron アプリでも動作します。
- **ショートカットはそのまま。** ラベルの表示中も、⌘C、⌘V、⌘W、Spotlight など、Spray Can が使わないショートカットは引き続き使えます。
- **フォーカスに追従。** タブ、ウインドウ、アプリを切り替えると（⌘Tab でも）、新しいラベルが表示されます。
- **ネイティブ。** Swift と AppKit で作られ、macOS 26 では Liquid Glass に対応。インターフェイスは 6 言語で利用できます。

## 4 つのモード

| モード | ショートカット | 用途 |
| --- | --- | --- |
| **要素** | ⇧⌘J | ボタン、リンク、行、フィールド、OCR テキスト |
| **グリッド** | ⇧⌘K | どのディスプレイの任意の位置にも |
| **フリースタイル** | ⇧⌘L | ポインタを少しずつ、またはセル単位で移動 |
| **スクロール** | ⌃J | HJKL でのスクロール、半ページ移動、先頭と末尾へのジャンプ |

グローバルショートカットはすべて設定で変更できます。

## 早見表

| キー | 操作 |
| --- | --- |
| ラベルを入力 | ポインタをその場所へ移動 |
| **Return** | クリック · 素早く 2 回: ダブルクリック · 長押し: 右クリック |
| `]` / `[` / `\` | 右クリック / 中クリック / ダブルクリック |
| **Space** または `=` | ボタンを押したままにしてドラッグ。もう一度押すとドロップ |
| 矢印 · ⌥ 矢印 | ポインタを少し移動 · 1 セル分移動 |
| ⇧ 矢印 | スクロール |
| **Esc** | 入力した文字をクリアし、もう一度押すと終了 |

Emacs と vi のキー割り当てを含む全一覧は [SHORTCUTS.md](docs/SHORTCUTS.md) を参照してください。

## 自分好みにカスタマイズ

![外観の設定](docs/images/appearance.png)

- ラベルの位置、サイズ、オフセット、Liquid Glass または無地の背景
- 5 つの配色による色分け、要素の塗り、塗りの不透明度
- スクロールの滑らかさと、スクロールモードでのポインタの位置
- ラベルの入力が完了したらすぐにクリック、Return を 2 回押してダブルクリック
- OCR のオン/オフと、テキスト認識の言語
- すべてのグローバルショートカットと、オプションの vi のキー割り当て

## インストール

```sh
brew install --cask kymer0615/tap/spray-can
open "/Applications/Spray Can.app"
```

アップデートは `brew update && brew upgrade --cask kymer0615/tap/spray-can`、削除は `brew uninstall --cask spray-can` で行います（環境設定は保持されます）。[Releases](https://github.com/Kymer0615/spray_can/releases) からユニバーサル ZIP をダウンロードし、**Spray Can.app** を「アプリケーション」フォルダに移動してインストールすることもできます。

Spray Can は以下の権限を要求します。

1. **アクセシビリティ**: コントロールの検出、ナビゲーションキーのキャプチャ、ポインタの移動、クリック、ドラッグ、スクロールに使います。
2. **画面収録**（オプション）: デバイス上の OCR と、ラベルの隣に置くテキストの検出にのみ使います。

リリースは **プロジェクト独自の証明書で署名されており、公証されていません**。すべてのリリースを同じ証明書で署名しているため、アップデートしても macOS は Spray Can の権限を保持します（0.1.7 以降）。初回起動が macOS にブロックされた場合は、**システム設定 → プライバシーとセキュリティ → このまま開く** を使ってください。リリースアーカイブとその SHA-256 チェックサムはバージョン管理されています。[リリース手順](docs/RELEASING.md)を参照してください。

## プライバシー

すべての処理はお使いの Mac 上で行われます。OCR はデバイス上の Apple Vision を使い、スクリーンショットはメモリ内で処理されて破棄されます。スクリーンショットのログ、分析、クラウド推論は一切なく、アカウントも不要です。**テキストラベルを事前に準備** をオンにすると、ウインドウに切り替えて約 1 秒後にも同じ方法でそのウインドウを読み取ります（電源接続時のみ）。結果はメモリ内にのみ保持されます。

## OCR

OCR は**複数の言語を同時に**読み取れます。言語の選択と並べ替えは **一般 → テキスト認識の言語** で行います。英語、フランス語、スペイン語のように同じ文字体系を持つ言語はまとめて認識されます。中国語、日本語、韓国語のように文字体系が増えるごとに、同じスクリーンショットに対する認識処理が 1 回追加されるため、スキャンに少し時間がかかります。デフォルトでは、Spray Can は Mac の優先言語と英語を選択します。認識するのは対象のウインドウだけです。**一般 → 対象 → テキストラベルを事前に準備**（デフォルトはオフ）をオンにすると、事前に読み取ってテキストラベルをすぐに表示できます。

OCR が認識するのはテキストの位置であり、クリックできるかどうかではないため、テキストのラベルが見出しを指すことがあります。ラベルのないアイコンやカスタムキャンバスには、グリッドを使ってください。互換性とテスト状況については [VALIDATION.md](docs/VALIDATION.md) を参照してください。

## ソースからビルド

**Xcode 26 以降** が必要です。

```sh
scripts/test.sh            # core tests + localization check
scripts/build.sh           # universal Release build
scripts/install-local.sh
```

その他のツール: `scripts/render-docs.sh`（README の画像）、`scripts/snapshot-labels.sh`（実際のウインドウに重ねたラベル）、`scripts/integration-test.sh`、`swift scripts/ocr-smoke.swift`、`python3 scripts/check-localizations.py`。`SprayCanCore` にはセッションのステートマシン、ラベルの配置などの純粋なロジックが、`Sources/SprayCanApp` にはアプリ本体、イベントキャプチャ、検出、オーバーレイが含まれます。[AGENTS.md](AGENTS.md) と[アーキテクチャノート](docs/ARCHITECTURE.md)を参照してください。

## ステータス

Spray Can 0.1.16 は macOS 14 以降で動作します。ナビゲーションのコアは 1,000 回の高速な起動サイクルによるストレステストを経ており、ネイティブのテスト用アプリでは 60 回の要素/グリッドのクリックサイクルを、クリックの取りこぼしや入力の漏れなく完了しました。サードパーティ製アプリ、複数ディスプレイ、フルスクリーン、古いバージョンの macOS は現在も検証中です。[VALIDATION.md](docs/VALIDATION.md) を参照してください。
