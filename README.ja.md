Spray Can を使えば、**マウスに手を伸ばさずに、クリック、ドラッグ、スクロール、ナビゲーションができます**。

**⇧⌘J** を押して、ラベルを入力し、**Return** を押すだけです。

macOS のアクセシビリティだけに頼るツールとは異なり、Spray Can は **Apple Vision OCR を完全にデバイス上で**使い、アプリがアクセシビリティツリーに公開していない表示中のテキストにもラベルを付けられます。

スクリーンショットが Mac の外に出ることはありません。

## もっと見える。すべてに届く。

Spray Can は 3 つのターゲット層を組み合わせています。

- **アクセシビリティ** — コントロール、ボタン、フィールド、行、メニュー、システム UI を正確に捉えます。
- **デバイス上の OCR** — アクセシビリティで公開されていない表示中のテキストを認識します。
- **グリッド** — カスタムキャンバスやラベルのない領域など、それ以外のあらゆる場所に届きます。

OCR は **ScreenCaptureKit + Apple Vision** を使い、ローカルで動作します。キャプチャしたフレームはメモリ内で処理されて破棄されます。クラウド推論、スクリーンショットのログ、分析は一切ありません。

![要素のワークフロー](docs/images/element-demo.gif)

## 4 つのナビゲーション方法

| モード | ショートカット | 用途 |
| --- | --- | --- |
| **要素** | ⇧⌘J | アクセシブルなコントロール + OCR テキスト |
| **グリッド** | ⇧⌘K | 接続されたすべてのディスプレイ上の任意の位置 |
| **フリースタイル** | ⇧⌘L | キーボードによる精密なポインタ移動 |
| **スクロール** | ⌃J | Vim 風の HJKL スクロール |

グローバルショートカットはすべて自由に設定できます。

## 作業の邪魔をしない設計

Spray Can は、ナビゲーション中も対象アプリのフォーカスを保ちます。

キーボード入力はオーバーレイとは独立してキャプチャされるため、要素の検出や OCR がバックグラウンドで続いている間でも、すぐに入力を始められます。入力を始めた後に遅れて届いた OCR 結果がラベルを変えることはありません。

クリックの前にアクセシブルなターゲットを再検証し、古いターゲットによるエラーを減らします。

ラベルはフォーカスに追従します。タブの切り替え、ウインドウを開く、ウインドウの移動やサイズ変更、⌘Tab やクリックによる別アプリへの移動などで対象ウインドウが変わると、Spray Can は再検索して新しいラベルを表示します。途中まで入力したラベルはクリアされ、進行中のドラッグは予期しない場所にドロップされるのではなくキャンセルされます。グリッドモードとフリースタイルモードは画面全体を対象とするため、影響を受けません。

## 密集したインターフェイスでも見やすいラベル

ラベルはデフォルトで要素の**横**に表示されるため、これからクリックするものを隠すことはありません。**外観**で左・右・上・下・要素の上に重ねる のいずれかを選び、水平・垂直オフセットで配置を微調整できます。

密集したラベルは、単に重なり合うのではなく、近くのコントロールを避けるように自動でずれます。コネクタ線によって、ずれたラベルがどのターゲットに対応するかがはっきりわかります。

![縦方向・横方向のクラスタに対するアダプティブな配置](docs/images/clustered-labels.png)

## ドラッグ、クリック、スクロール

Spray Can は以下に対応しています。

- 左クリック、中クリック、右クリック、ダブルクリック
- 修飾キー付きクリック
- ドラッグ＆ドロップ
- 細かい移動とセル単位のポインタ移動
- 画面端へのジャンプ
- Vim 風のスクロール
- 複数ディスプレイ

ドラッグの例:

`⇧⌘K` → ドラッグ元のラベルを入力 → `=` → ドロップ先のラベルを入力 → `Return`

## macOS ネイティブの体験

![設定](docs/images/settings.png)

Spray Can は Swift と AppKit で作られています。

**macOS 26 以降では Liquid Glass**、macOS 14–15 ではネイティブのマテリアルを使用し、「透明度を下げる」の設定にも従います。外観で **Liquid Glass を使用** をオフにすると、ラベルとステータスパネルの背景が無地になります。ガラスをオフにすると、文字を薄くすることなくラベル背景の不透明度を調整できます。ガラスまたは「透明度を下げる」が有効な間は、スライダは無効になります。

カスタマイズできる項目:

- ナビゲーションのショートカット
- ターゲットの範囲
- OCR とその認識言語
- vi のキー割り当て
- ラベルの位置とオフセット
- ラベルのサイズ
- グリッドの間隔
- 背景の不透明度
- ラベル、OCR、グリッド、文字、選択の色
- インターフェイスの言語

Spray Can のインターフェイスは English、简体中文、繁體中文、日本語、한국어、Español で利用できます。デフォルトでは Mac の言語設定に従います。別の言語を使うには **一般 → 言語** で選択し、確認が表示されたら Spray Can を再起動してください。

![外観のカスタマイズ](docs/images/appearance.png)

## インストール

[私の Homebrew tap](https://github.com/Kymer0615/homebrew-tap) からインストールします。

```sh
brew install --cask kymer0615/tap/spray-can
open "/Applications/Spray Can.app"
```

アップデートまたは削除するには:

```sh
brew update
brew upgrade --cask kymer0615/tap/spray-can
brew uninstall --cask spray-can
```

通常のアンインストールでは環境設定は保持されます。手動でインストールしていた場合は、2 つのコピーが同時に動作しないよう、Homebrew に切り替える前に Spray Can を終了し、そのコピーを「アプリケーション」フォルダから移動してください。

または、[Releases](https://github.com/Kymer0615/spray_can/releases) からユニバーサル ZIP をダウンロードして展開し、**Spray Can.app** を「アプリケーション」フォルダに移動してください。

リリース 0.1.2 は **アドホック署名で、公証されていません**。信頼できるビルドを macOS がブロックした場合は、次の操作を行ってください。

**システム設定 → プライバシーとセキュリティ → このまま開く**

Spray Can は以下の権限を要求することがあります。

1. **アクセシビリティ** — コントロールの検出、ナビゲーションキーのキャプチャ、ポインタ操作の実行に使います。
2. **画面収録** — オプションで、デバイス上の OCR にのみ使います。

キーボードキャプチャにはアクセシビリティの権限を使うため、入力監視を別途設定する必要はありません。権限ページでは、キャプチャが実際に動作しているかどうかを確認できます。

リリースアーカイブとその SHA-256 チェックサムはバージョン管理されています。[リリース手順](docs/RELEASING.md)を参照してください。

## プライバシー

Spray Can はローカルで動作するように設計されています。

- OCR は **デバイス上の Apple Vision** で実行
- スクリーンショットはメモリ内で処理して破棄
- スクリーンショットのログなし
- 分析なし
- クラウド推論なし
- アカウントやサブスクリプションは不要

## OCR の言語

OCR は**複数の言語を同時に**読み取れます。**一般 → テキスト認識の言語** で、お使いの Mac で Apple Vision が対応している言語を自由に選び、順番を並べ替えられます。選択したすべての言語のテキストに 1 回のスキャンでラベルが付くため、英語のツールバー、中国語の文書、日本語のメニューにまとめてアクセスできます。

英語、フランス語、スペイン語のように同じ文字体系を持つ言語は、まとめて認識されます。中国語、日本語、韓国語のように文字体系が増えるごとに、同じスクリーンショットに対する認識処理が 1 回追加されるため、スキャンに少し時間がかかります。デフォルトでは、Spray Can は Mac の優先言語と英語を選択します。

## OCR の制限

OCR が認識するのは**テキストの位置**であり、そのテキストがクリックできるかどうかではありません。

そのため、認識されたラベルが見出しなど操作できないテキストを指すことがあります。また、ラベルのないアイコンや任意の視覚的なコントロールをすべて検出できるわけではありません。

そのような場合は **グリッドモード** を使ってください。

現在の互換性とテスト状況については [VALIDATION.md](docs/VALIDATION.md) を参照してください。

## ビルド

**Xcode 26 以降** が必要です。

```sh
scripts/test.sh
scripts/build.sh
scripts/install-local.sh
```

開発用:

```sh
swift scripts/generate-artwork.swift
python3 scripts/generate-project.py
scripts/render-docs.sh
scripts/integration-test.sh
swift scripts/ocr-smoke.swift
swift scripts/ocr-smoke.swift image.png --languages en-US,zh-Hans,ja-JP --expect "Open,打开,開く"
python3 scripts/check-localizations.py
scripts/release.sh 0.1.2 adhoc
```

Xcode で `SprayCan.xcodeproj` を開きます。

インターフェイスの翻訳は `Resources/<language>.lproj/Localizable.strings` にあり、英語のキーが原文です。`scripts/check-localizations.py` は、すべての言語にすべてのキーがあり、プレースホルダが一致していることを確認します。

`SprayCanCore` には、セッションのステートマシン、ラベルの生成と配置、OCR 言語のグループ化、更新ルール、ジオメトリ、ショートカットの対応付けが含まれます。`Sources/SprayCanApp` には、アプリの UI、イベントキャプチャ、検出プロバイダ、マウスドライバ、オーバーレイが含まれます。

## ステータス

Spray Can 0.1.2 は macOS 14 以降で利用できます。

ナビゲーションのコアは **1,000 回の高速な起動サイクル**によるストレステストを経ており、ネイティブのテスト用アプリでは **60 回の要素/グリッドのクリックサイクル**を、クリックの取りこぼしや入力の漏れなく完了しました。

サードパーティ製アプリ、複数ディスプレイ、フルスクリーン、バージョン間の互換性は、現在も検証中です。

[VALIDATION.md](docs/VALIDATION.md) を参照してください。
