This is an **unnotarized preview**, signed ad hoc rather than with an Apple Developer ID. It is intended for testing. macOS may require Open Anyway in Privacy & Security, and Accessibility/Input Monitoring permissions must be granted before navigation works.

Download the universal ZIP for Apple Silicon and Intel Macs running macOS 14 or later. The SHA-256 sidecar verifies the download; `spray-can.rb` is the matching Homebrew cask for a future tap.

Includes element, grid, freestyle, and scroll-area navigation; Scoot-compatible defaults; optional local OCR; original spray-can icons; and native macOS visuals. See the repository's README and `docs/VALIDATION.md` for usage, verified tests, and outstanding compatibility checks. General Homebrew publication and Developer ID notarization are not enabled yet.
